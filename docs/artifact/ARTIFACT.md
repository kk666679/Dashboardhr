# AHROS Artifact Platform — Complete Data Model & Implementation Guide

As the Chief Architect, I am delivering the **definitive Artifact Data Models** for the AHROS platform. 

These artifacts are not passive logs; they are the **single source of truth** for the entire system. Every AI decision, business execution, compliance check, and learning loop is captured as a versioned, linked, and synchronized artifact. 

By implementing these schemas, we fulfill **Deliverable #8 (Artifact Synchronization Model)** and provide the foundation for the **Knowledge, Compliance, and Audit platforms**.

---

## 1. Base Artifact Interface (Abstract Schema)

All artifacts extend this base, ensuring universal versioning, traceability, and synchronization.

```typescript
// ============================================================
// CORE: Base Artifact (Abstract)
// ============================================================
export enum ArtifactType {
  CONVERSATION = 'conversation',
  INTENT = 'intent',
  PLAN = 'plan',
  WORKFLOW = 'workflow',
  REASONING = 'reasoning',
  EXECUTION = 'execution',
  TIMELINE = 'timeline',
  AUDIT = 'audit',
  COMPLIANCE = 'compliance',
  KNOWLEDGE = 'knowledge',
  SOP = 'sop',
  SIMULATION = 'simulation',
  CHECKPOINT = 'checkpoint',
  LEARNING = 'learning',
}

export enum ArtifactStatus {
  DRAFT = 'draft',
  ACTIVE = 'active',
  EXECUTING = 'executing',
  COMPLETED = 'completed',
  FAILED = 'failed',
  ARCHIVED = 'archived',
  PENDING_REVIEW = 'pending_review',
}

export interface BaseArtifact {
  id: string;                     // UUID v7 (time-sortable)
  version: number;                // Semantic versioning for the artifact
  type: ArtifactType;
  status: ArtifactStatus;
  
  // Provenance & Metadata
  createdAt: string;              // ISO 8601
  updatedAt: string;
  createdBy: string;              // User ID or 'system' | 'ai-agent'
  source: 'user' | 'ai' | 'system' | 'integration';
  tenantId: string;               // Multi-tenancy isolation
  
  // Linking (The Synchronization Graph)
  relatedTo: {                    // Establishes the DAG (Directed Acyclic Graph)
    [key in ArtifactType]?: string[]; 
  };
  rootEventId: string;            // The original Business Event ID that started this chain
  
  // Integrity & Storage
  checksum: string;               // SHA-256 for integrity validation
  sizeBytes: number;
  storagePath: string;            // S3/GCS path or DB reference
  
  // Security
  accessLevel: 'public' | 'team' | 'confidential' | 'restricted';
  retentionPolicy: 'standard' | 'legal_hold' | 'temporary';
}
```

## 3. Artifact Synchronization Engine Logic

To ensure the **"Never duplicate information"** principle, we implement a reactive synchronization engine.

```typescript
// Psuedo-code for the Sync Engine
class ArtifactSyncEngine {
  // When a workflow is updated, find all dependent artifacts and update them
  async onWorkflowUpdated(workflowId: string) {
    const dependents = await this.artifactStore.find({
      'relatedTo.workflow': workflowId,
      status: 'active'
    });

    for (const artifact of dependents) {
      switch (artifact.type) {
        case ArtifactType.SIMULATION:
          // Automatically re-run simulation with new workflow
          await this.simulationService.reRun(artifact.id);
          break;
        case ArtifactType.EXECUTION:
          // Flag executions based on old workflow as 'deprecated'
          await this.setStatus(artifact.id, 'archived');
          break;
        case ArtifactType.SOP:
          // Regenerate the SOP based on the new logic
          await this.knowledgeService.regenerateSOP(artifact.id);
          break;
      }
    }
  }
}
```

## 4. Storage & Indexing Strategy

| Artifact Type | Storage Layer | Indexing Strategy | TTL |
| :--- | :--- | :--- | :--- |
| **Conversation, Reasoning** | Document DB (MongoDB) | `tenantId + createdAt` | Standard (90d) |
| **Workflow, Plan, SOP** | Document DB + Blob (JSON) | `type + versionTag` | Permanent |
| **Execution, Logs** | Time-Series DB (InfluxDB) / Parquet | `workflowId + timestamp` | Standard (180d) |
| **Audit, Compliance** | Immutable Ledger / Document DB | `resourceId + action` | Legal Hold (7yrs) |
| **Knowledge, Embeddings** | Vector DB (Pinecone) + S3 | Semantic Search (Cosine Similarity) | Permanent |
| **Checkpoint** | Redis (Cache) + S3 (Archive) | `executionId` | 7 days (Cache) |

## 5. Developer Implementation Guide

To generate a new artifact, use the **Artifact Factory**.

```typescript
export class ArtifactFactory {
  static async create<T extends BaseArtifact>(
    type: ArtifactType, 
    payload: Partial<T>, 
    context: { user: string; tenant: string; rootEvent: string }
  ): Promise<T> {
    const artifact: T = {
      id: generateUuidV7(),
      version: 1,
      type,
      status: ArtifactStatus.DRAFT,
      createdAt: new Date().toISOString(),
      updatedAt: new Date().toISOString(),
      createdBy: context.user,
      tenantId: context.tenant,
      rootEventId: context.rootEvent,
      relatedTo: {},
      checksum: await this.generateChecksum(payload),
      ...payload,
    } as T;

    // Store and automatically trigger Sync Engine
    await this.store.save(artifact);
    await this.syncEngine.onArtifactCreated(artifact);
    
    return artifact;
  }
}
```
